Politique de confidentialité.

Dernière mise à jour : 31 juillet 2026

1. Introduction

Bienvenue sur les services numériques de ZEMA TECHNOLOGIES.

La présente Politique de confidentialité explique comment nous collectons, utilisons, protégeons et traitons les informations personnelles lorsque vous utilisez nos solutions numériques, nos assistants intelligents, nos plateformes web, nos applications ou tout autre service développé par ZEMA TECHNOLOGIES.

Notre objectif est de garantir une utilisation transparente, sécurisée et responsable de vos données personnelles.

2. Qui sommes-nous ?

ZEMA TECHNOLOGIES est une entreprise spécialisée dans :

  • le développement de solutions d'intelligence artificielle ;
  • les assistants conversationnels, chatbots et voicebots ;
  • l'automatisation des processus métier ;
  • les sites web et applications ;
  • les plateformes numériques ;
  • les solutions de communication digitale.

Nos solutions peuvent être utilisées directement par ZEMA TECHNOLOGIES ou être mises à disposition de nos clients.

3. Données collectées

Selon le service utilisé, nous pouvons collecter :

Informations d'identification

  • nom ;
  • prénom ;
  • numéro de téléphone ;
  • adresse e-mail.

Informations liées aux échanges

  • messages texte ;
  • conversations ;
  • demandes envoyées aux assistants IA ;
  • commandes ;
  • réservations ;
  • formulaires.

Médias

  • images ;
  • documents ;
  • fichiers ;
  • messages vocaux.

Localisation

Lorsque vous choisissez volontairement de partager votre position via une application compatible, par exemple WhatsApp, nous pouvons traiter :

  • votre localisation ;
  • vos coordonnées GPS ;
  • les informations permettant d'assurer un service de livraison ou de localisation.

Informations techniques

Selon le service utilisé :

  • type d'appareil ;
  • navigateur ;
  • système d'exploitation ;
  • adresse IP ;
  • journaux techniques ;
  • informations nécessaires à la sécurité des services.

4. Finalités du traitement

Les données sont utilisées notamment pour :

  • répondre à vos demandes ;
  • fournir nos services numériques ;
  • gérer les commandes et réservations ;
  • automatiser certaines tâches ;
  • améliorer nos assistants intelligents ;
  • assurer le support technique ;
  • garantir la sécurité des services ;
  • prévenir les utilisations frauduleuses ;
  • respecter nos obligations légales.

5. Intelligence artificielle

Certaines fonctionnalités utilisent des technologies d'intelligence artificielle afin de :

  • comprendre vos demandes ;
  • générer des réponses ;
  • traiter des documents ;
  • analyser des images ;
  • transcrire des messages vocaux ;
  • automatiser certaines opérations.

Ces traitements sont réalisés uniquement pour fournir les services demandés.

6. Partage des données

Nous ne vendons jamais vos données personnelles.

Vos informations peuvent uniquement être partagées avec :

  • nos collaborateurs autorisés ;
  • nos clients lorsque nous agissons en leur nom, par exemple un restaurant utilisant notre assistant IA ;
  • nos prestataires techniques indispensables au fonctionnement des services.

Ces prestataires peuvent notamment inclure :

  • Meta, WhatsApp Business Platform ;
  • OpenAI ;
  • Anthropic ;
  • Groq ;
  • fournisseurs d'hébergement ;
  • services d'automatisation ;
  • plateformes de paiement ;
  • autres partenaires techniques strictement nécessaires.

7. Paiements

Lorsque nos solutions permettent un paiement, celui-ci est réalisé via les moyens de paiement proposés par nos clients ou nos partenaires.

Les informations bancaires complètes ne sont pas stockées par ZEMA TECHNOLOGIES.

8. Conservation des données

Les données sont conservées uniquement pendant la durée nécessaire :

  • à la fourniture du service ;
  • au traitement des demandes ;
  • au respect des obligations légales ;
  • à l'amélioration des services.

Les durées de conservation peuvent varier selon le service concerné.

9. Sécurité

Nous mettons en oeuvre des mesures techniques et organisationnelles destinées à protéger les données contre :

  • l'accès non autorisé ;
  • la perte ;
  • l'altération ;
  • la divulgation.

Malgré ces mesures, aucun système informatique ne peut garantir une sécurité absolue.

10. Vos droits

Selon la réglementation applicable, vous pouvez demander :

  • l'accès à vos données ;
  • leur rectification ;
  • leur suppression ;
  • la limitation de leur traitement ;
  • leur portabilité lorsque cela est applicable.

Vous pouvez également retirer votre consentement lorsque celui-ci constitue la base légale du traitement.

11. Cookies

Nos sites web peuvent utiliser des cookies afin :

  • d'assurer leur bon fonctionnement ;
  • d'améliorer l'expérience utilisateur ;
  • de mesurer l'utilisation des services.

Vous pouvez gérer les cookies depuis les paramètres de votre navigateur.

12. Services de tiers

Nos solutions peuvent intégrer des services tiers tels que :

  • WhatsApp Business Platform, Meta ;
  • OpenAI ;
  • Anthropic ;
  • Groq ;
  • Google ;
  • fournisseurs de paiement ;
  • services cloud ;
  • plateformes d'automatisation.

L'utilisation de ces services est soumise à leurs propres politiques de confidentialité.

13. Solutions développées pour nos clients

ZEMA TECHNOLOGIES développe des solutions numériques pour différents secteurs d'activité.

Lorsqu'un assistant ou une plateforme est développé pour le compte d'un client, certaines données peuvent être traitées pour le compte de ce client conformément aux finalités du service concerné.

14. Protection des mineurs

Nos services ne sont pas destinés à collecter volontairement des données personnelles auprès d'enfants sans l'autorisation requise de leur représentant légal lorsque celle-ci est applicable.

15. Modifications de la présente politique

Cette Politique de confidentialité peut être mise à jour à tout moment.

La date de dernière mise à jour figurera en haut de cette page.
